# 2QB / Superflex Trade Values

Two charts, both current for the 2026 season: **The Score** (as captured from the TX2025 screenshots) and **FantasyPros Pro**. Each gives a 1QB value and an SF (Superflex/2QB) value per draft-pick slot; players are valued by mapping them to the pick slot they'd command.

**Always use the SF column for TX2025.** The 1QB column is included only so it's clear which one *not* to use — applying 1QB values in a 2QB league systematically undervalues quarterbacks, which is the most common way to lose a trade in this format.

## The method

1. Look up each player in both charts, SF column.
2. Average the two values per player. The charts agree closely at the top and diverge in the middle rounds, so averaging smooths out chart-specific quirks rather than betting on one source.
3. Sum each side; compare. **Within ±5 points is fair.** Larger gaps mean value is moving, and the write-up should say which direction and by how much.
4. Then apply roster context (see `tx2025.md`) — the charts don't know about byes, playoff schedules, or that David is starting a zero at RB2.

## Worked example

> Give: Lamar Jackson + Tyler Higbee. Get: Patrick Mahomes + Tee Higgins.

| | The Score | FantasyPros | Avg |
|---|---|---|---|
| Lamar Jackson | 64 | 64 | 64 |
| Tyler Higbee | 15 | 18 | 16.5 |
| **David's side** | 79 | 82 | **80.5** |
| Patrick Mahomes | 58 | 59 | 58.5 |
| Tee Higgins | 34 | 35 | 34.5 |
| **Their side** | 92 | 94 | **93** |

Delta: **+12.5 to the opponent.** That's outside the fair band, so the raw value says decline — but he's swapping a TE2 for a WR1, which is a real lineup upgrade if his WR3 is a weak spot. Verdict shape: decline as offered, counter by asking for a mid-round piece to close the gap, and note that the opponent is deep at QB and therefore gains less from Lamar than the chart implies.

## Chart caveats

These are references, not gospel. They're static snapshots that don't move with injuries or breakouts, they value players by draft-slot equivalence rather than by current form, and they can't see roster context. When the chart and the obvious football answer disagree, say so explicitly rather than hiding behind the numbers.
